# Mulkey Studios Website

Static website for Mulkey Studios, designed for GitHub Pages.

## Files
- `index.html`
- `style.css`
- `mulkey-studios-logo.jpeg`

## Before publishing
Replace every `YOUR_GOOGLE_FORM_LINK_HERE` in `index.html` with the public Google Form application link.

## GitHub Pages
Upload these files to a GitHub repository, then enable GitHub Pages from the repository settings.
